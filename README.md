# 느낌표수학학원 홈페이지 (exclamath.com)

주엽동 초·중·고 수학전문 학원의 원페이지 홈페이지 + 시간표.

## 잔여석 갱신 방법 (매주 월요일)

시간표의 모든 숫자는 **`data/timetable.ts` 파일 한 곳**에만 있습니다.
매주 월요일에 이 파일을 열어 ① 맨 위쪽 `seatsAsOf`의 날짜를 오늘 날짜로 바꾸고,
② `classes` 목록에서 각 반의 `seats:` 뒤 숫자를 실제 잔여석으로 바꾸면 됩니다.
자리가 다 찬 반은 `seats`를 0으로 하고 `status`를 `"정원마감"`으로 바꿉니다.
저장 후 배포하면 시간표 페이지와 홈 화면 모집 블록이 **함께** 바뀝니다.
다른 파일은 건드릴 필요가 없고, 다른 파일에 숫자를 쓰면 안 됩니다.

상태는 네 가지만 씁니다: `진행중` · `10월개강` · `정원마감` · `상시`(개강 준비반 전용).
다음 과정 안내는 `nextNote`("11월 1일에 공통수학2를 시작합니다"),
홈 화면 안내 문장은 `joinPitch`에 적습니다. 반의 시작일과 현재 진도는 쓰지 않습니다.
