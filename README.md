# 느낌표수학학원 홈페이지 (exclamath.com)

주엽동 초·중·고 수학전문 학원의 원페이지 홈페이지 + 시간표.

## 반 상태 갱신 방법

시간표의 모든 반 정보는 **`data/timetable.ts` 파일 한 곳**에만 있습니다.
잔여석 숫자는 사이트에 표시하지 않습니다 (2026-10-19 원장 지시). 화면에는
"진행 중 · 접수 중" / "정원 마감 · 대기 접수" / "상시 접수 · 원비 동일" 세 가지 상태만 보입니다.
자리가 다 찬 반은 `status`를 `"정원마감"`으로, 자리가 다시 나면 `"진행중"`으로 바꿉니다.
(`seats` 숫자는 내부 기록용이라 바꿔도 화면에는 나오지 않습니다.)
저장 후 배포하면 시간표 페이지와 홈 화면 모집 블록이 **함께** 바뀝니다.
다른 파일은 건드릴 필요가 없고, 다른 파일에 숫자를 쓰면 안 됩니다.

상태는 세 가지만 씁니다: `진행중` · `정원마감` · `상시`(개강 준비반 전용).
다음 과정 안내는 `nextNote`("○월 ○일에 ○○를 시작합니다"),
홈 화면 안내 문장은 `joinPitch`에 적습니다. 반의 시작일과 현재 진도는 쓰지 않습니다.
